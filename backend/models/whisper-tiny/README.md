# Whisper Tiny (Quantized CTranslate2 int8)

This directory stores the on-device quantized Whisper `tiny` model for 100% offline speech-to-text inference.

## Model Details
- **Architecture**: Whisper Tiny
- **Format**: CTranslate2 (int8 quantized)
- **Parameters**: ~39M
- **Engine**: faster-whisper / CTranslate2
- **Privacy**: 100% On-Device, zero cloud transmission
